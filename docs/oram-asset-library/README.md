# ORAM Asset Library (Launch Standard)

This library is the **source of truth** for publication media.  
Website `public/` files are **delivery copies only** after Rights + Approval are signed.

**Rule:** No social-media downloads. No screenshots. No assumed licences.  
If ownership is unknown → `REQUIRES PERMISSION`.

## Status legend

| Status | Meaning |
|--------|---------|
| ORAM-owned | Created by Oram / Owas Films under work-for-hire or company ownership |
| Client-owned | MultiChoice, MoYSA, etc. — needs written web licence |
| Licensed | Third-party brand mark used under brand guidelines / written OK |
| Unknown | Treat as **REQUIRES PERMISSION** |

Each project folder must eventually contain masters (not web compressions) for:

| Slot | Spec |
|------|------|
| Hero | ≥2400px long edge, graded still or silent loop poster |
| Landscape | 16:9 production still |
| Portrait | Poster / 3:4 key art |
| Behind the Scenes | Set photography, Oram-owned preferred |
| Trailer | Master MP4 + YouTube ID + embed rights note |
| Poster | Print/PDF or TIFF key art |
| Gallery | 3–12 cleared stills |
| Credits | Call sheet / PDF |
| Logo | Title treatment if any |
| Metadata | synopsis, year, client, channels (sourced) |
| Rights | Who owns what; permission email on file |
| Approval | Named approver + date for web use |
